Minecraft Java 26.3 auf dem USB-Stick

Schritt-für-Schritt-Anleitung für Windows-Schulrechner · Prism Launcher Portable · Vanilla Minecraft
Stand: 18. November 2026

Anleitung als PDF herunterladen

Das Ziel: Minecraft Java 26.3 von einem USB-Stick starten, ohne den offiziellen Minecraft-Launcher auf jedem Schulrechner zu installieren. Der portable Prism Launcher speichert seine Spieldaten im eigenen Ordner. Voraussetzung: Die Schule erlaubt den Start von Anwendungen vom USB-Stick.

1 · Das wird benötigt

  • USB-Stick mit mindestens 16 GB; empfohlen sind 32–64 GB und USB 3.0 oder schneller.
  • Windows 10 oder 11 (64 Bit), Internetzugang zur Einrichtung und geeignete Grafiktreiber.
  • Eigenes Microsoft-Konto mit gültiger Lizenz für Minecraft: Java Edition.
  • Prism Launcher Portable und eine zu Minecraft 26.3 passende Java-Laufzeit (Java 25).

2 · Prism Launcher herunterladen und entpacken

Öffne prismlauncher.org/download/windows/. Wähle unter x86-64 die Datei Portable (.zip) (nicht den Installer). Entpacke den gesamten ZIP-Inhalt in einen Ordner auf dem USB-Stick, z. B. E:\Minecraft-AG\.

Die Datei prismlauncher.exe liegt anschließend im entpackten Ordner. Starte sie per Doppelklick. Der Laufwerksbuchstabe kann auf einem anderen PC abweichen.

3 · Java 25 automatisch verwalten

Im Prism Launcher: Einstellungen → Java. Aktiviere Autodetect Java version und Auto-download Mojang Java (die Bezeichnungen können je nach Sprache etwas anders lauten). Prism kann die erforderliche Laufzeit dann selbst herunterladen. Über Ordner → Launcher Root lässt sich der portable Datenordner prüfen.

Für Vanilla sind 3–4 GiB maximal zugewiesener Arbeitsspeicher ein sinnvoller Ausgangspunkt; auf Rechnern mit wenig RAM entsprechend weniger wählen.

4 · Minecraft 26.3 (Vanilla) einrichten

Klicke auf Instanz hinzufügen, wähle die offizielle Release-Version 26.3 und keinen Mod-Loader. Vergib beispielsweise den Namen Minecraft 26.3 Vanilla und bestätige die Auswahl.

5 · Mit Microsoft anmelden und starten

Öffne Accounts → Accounts verwalten → Microsoft hinzufügen. Folge der Anmeldung im Browser (ggf. mit Einmalcode und zweitem Faktor). Wähle anschließend die Instanz Minecraft 26.3 Vanilla und klicke Starten. Beim ersten Start werden zusätzliche Dateien heruntergeladen.

6 · Minecraft-AG-Server hinzufügen

In Minecraft: Mehrspieler → Server hinzufügen. Trage den Namen der AG und die von der Schule genannte Serveradresse ein. Die vom Server unterstützte Spielversion muss zu deinem Client passen.

EinstellungBeispiel
ServernameMinecraft-AG
Serveradresse<Adresse eures Servers>

7 · An einem anderen Schulrechner spielen

USB-Stick anschließen → prismlauncher.exe aus dem portablen Ordner starten → gewünschte Instanz auswählen → spielen. Welten, Instanzen und Serverlisten bleiben bei korrekter portabler Einrichtung auf dem Stick. Ein neuer PC kann dennoch eine erneute Microsoft-Anmeldung erfordern.

8 · Typische Probleme

ProblemWas prüfen?
Launcher startet nichtErlaubt die Schulrichtlinie EXE-Dateien von USB?
Java-FehlerJava 25 eingestellt bzw. automatischer Download aktiviert?
Minecraft langsamUSB 3.x, ausreichend RAM, Grafikeinstellungen reduzieren.
Server nicht erreichbarAdresse, Version, Netzwerk und Firewall prüfen.
Anmeldung scheitertInternetzugang, Account-Lizenz und Microsoft-Bestätigung.

9 · Wichtig für die gemeinsame Nutzung

Datenschutz: USB-Sticks mit eingeloggtem Microsoft-Konto nicht unter Schülern weitergeben. Für mehrere Schüler die vorbereitete Launcher-Installation ohne persönliche Accounts und Tokens kopieren; jeder meldet sich mit seinem eigenen lizenzierten Konto an. Ein portabler Launcher umgeht keine schulischen Sicherheitssperren.

Hinweis zur Portabilität: Prism speichert bei der portablen Version seine Daten im Launcher-Ordner, einschließlich verwalteter Java-Installationen. Kontrolliere mit Ordner → Launcher Root, dass dieser Ordner tatsächlich auf dem Stick liegt. Windows kann dennoch temporäre Dateien auf dem Schulrechner erzeugen.
